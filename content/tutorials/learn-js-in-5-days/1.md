# Day 1: JavaScript Basics

Welcome to Day 1 of your JavaScript journey! Today we'll cover the fundamental building blocks: variables, data types, and functions.

## Variables in JavaScript

Variables are containers for storing data values. JavaScript provides three ways to declare variables:

### `let` — Block-scoped, reassignable

```js
let name = "Alice"
name = "Bob" // ✅ This works
console.log(name) // "Bob"
```

### `const` — Block-scoped, cannot be reassigned

```js
const pi = 3.14159
// pi = 3.14 // ❌ TypeError!
```

### `var` — Function-scoped (legacy, avoid)

```js
var oldSchool = "Don't use me in modern JS"
```

## Data Types

JavaScript has **7 primitive types** and **1 object type**:

| Type | Example |
|------|---------|
| `string` | `"hello"` |
| `number` | `42`, `3.14` |
| `boolean` | `true`, `false` |
| `null` | `null` |
| `undefined` | `undefined` |
| `symbol` | `Symbol("id")` |
| `bigint` | `9007199254740991n` |
| `object` | `{ name: "Alice" }` |

## Your First Function

Functions let you group code into reusable blocks:

```js
function greet(name) {
  return `Hello, ${name}!`
}

console.log(greet("World")) // "Hello, World!"
```

### Arrow Functions (Preview)

```js
const add = (a, b) => a + b
console.log(add(2, 3)) // 5
```

## 🧪 Mini Challenge

Create a function `calculateArea` that takes `width` and `height` parameters and returns the area of a rectangle.

<details>
<summary>Solution</summary>

```js
function calculateArea(width, height) {
  return width * height
}

console.log(calculateArea(5, 3)) // 15
```

</details>

## Key Takeaways

- Use `const` by default, `let` when you need to reassign
- JavaScript is dynamically typed — variables can hold any type
- Functions are first-class citizens in JavaScript
- Practice writing small functions to build muscle memory
