# Learn JavaScript in 5 Days

Welcome to this comprehensive 5-day JavaScript tutorial series! Whether you're a complete beginner or brushing up on fundamentals, this series will guide you through the core concepts of modern JavaScript.

## What You'll Learn

- **Day 1:** Variables, data types, and basic functions
- **Day 2:** Control flow — conditionals and loops
- **Day 3:** Arrays, objects, and destructuring
- **Day 4:** ES6+ features — arrow functions, template literals, spread/rest
- **Day 5:** Async JavaScript — promises and async/await

Each day includes practical examples and mini-challenges to reinforce your learning. Ready? Start with Day 1!
