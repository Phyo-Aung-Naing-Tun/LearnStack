# Day 2: Control Flow

Today we'll explore how to make decisions and repeat actions in your JavaScript code.

## Conditionals

### The `if...else` Statement

```js
const score = 85

if (score >= 90) {
  console.log("Grade: A")
} else if (score >= 80) {
  console.log("Grade: B")
} else if (score >= 70) {
  console.log("Grade: C")
} else {
  console.log("Grade: F")
}
// Output: "Grade: B"
```

### Ternary Operator

A concise way to write simple conditionals:

```js
const isLoggedIn = true
const message = isLoggedIn ? "Welcome back!" : "Please log in"
console.log(message) // "Welcome back!"
```

### Switch Statement

Useful for comparing a value against multiple cases:

```js
const day = "Monday"

switch (day) {
  case "Monday":
    console.log("Start of the work week!")
    break
  case "Friday":
    console.log("TGIF!")
    break
  default:
    console.log("It's a regular day.")
}
```

## Loops

### `for` Loop

```js
for (let i = 0; i < 5; i++) {
  console.log(`Iteration ${i + 1}`)
}
```

### `while` Loop

```js
let count = 1
while (count <= 3) {
  console.log(`Count: ${count}`)
  count++
}
```

### `for...of` — Iterate over arrays

```js
const fruits = ["apple", "banana", "cherry"]

for (const fruit of fruits) {
  console.log(fruit)
}
```

## Logical Operators

| Operator | Meaning |
|----------|---------|
| `&&` | Logical AND |
| `\|\|` | Logical OR |
| `!` | Logical NOT |

```js
const isWeekend = true
const isSunny = false

if (isWeekend && isSunny) {
  console.log("Let's go to the park!")
} else if (isWeekend || isSunny) {
  console.log("Still a decent day.")
} else {
  console.log("Stay home and code.")
}
```

## 🧪 Mini Challenge

Write a `fizzBuzz` function that prints numbers 1 to 15, but for multiples of 3 print "Fizz", multiples of 5 print "Buzz", and multiples of both print "FizzBuzz".

<details>
<summary>Solution</summary>

```js
function fizzBuzz() {
  for (let i = 1; i <= 15; i++) {
    if (i % 3 === 0 && i % 5 === 0) {
      console.log("FizzBuzz")
    } else if (i % 3 === 0) {
      console.log("Fizz")
    } else if (i % 5 === 0) {
      console.log("Buzz")
    } else {
      console.log(i)
    }
  }
}
```

</details>

## Key Takeaways

- Use `if...else` for branching logic
- Choose the right loop: `for` when count is known, `while` when condition-based
- `for...of` is the cleanest way to iterate arrays
- Logical operators let you combine multiple conditions
