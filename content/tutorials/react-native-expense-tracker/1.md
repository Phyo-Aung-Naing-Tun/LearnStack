# Part 1: Core Concepts

## 1.1 React Core (Web/Native နှစ်ခုစလုံးအတွက် အခြေခံ)

### Component
UI ရဲ့ ပြန်လည်အသုံးချနိုင်တဲ့ အပိုင်းအစ — function တစ်ခုက JSX return ပြန်တာ။

```jsx
function ExpenseCard() {
  return <Text>Lunch - 5000 Ks</Text>;
}
```

### Props
Component ကို parent ကနေ data ပို့တဲ့ **read-only** channel။

```jsx
function ExpenseCard({ title, amount }) {
  return <Text>{title}: {amount} Ks</Text>;
}

<ExpenseCard title="Lunch" amount={5000} />
```

### State
Component ကိုယ်တိုင် ပိုင်ဆိုင်ပြီး **ပြောင်းလို့ရတဲ့** data — ပြောင်းတိုင်း component ပြန် render ဖြစ်တယ်။

```jsx
const [amount, setAmount] = useState('');
```

> State ကို တိုက်ရိုက် mutate မလုပ်ရဘူး: `setExpenses([...expenses, newOne])` ✅, `expenses.push(newOne)` ❌

### Hooks
`use` နဲ့စတဲ့ function တွေ — component ထဲ feature ချိတ်ဖို့။
- **`useState`** — state ကိုင်တွယ်ဖို့
- **`useEffect`** — component mount/update ချိန်မှာ side-effect (data load/save) လုပ်ဖို့

```jsx
useEffect(() => {
  loadExpenses().then(setExpenses); // app စဖွင့်ချိန် တစ်ခါပဲ run
}, []);
```

**Hook Rules:** component/custom-hook ထဲမှာပဲ ခေါ်ရမယ်၊ loop/if ထဲမှာ ခေါ်လို့မရဘူး၊ order အမြဲတူရမယ်။

## 1.2 React Native Core (Web နဲ့ ကွာတဲ့ အပိုင်း)

### (a) HTML မရှိဘူး — Native Components

| Web | React Native |
|---|---|
| `<div>` | `<View>` |
| `<p>` | `<Text>` |
| `<input>` | `<TextInput>` |
| `<button>` | `<Pressable>` |
| `.map()` list | `<FlatList>` |

> Text ကို `<Text>` ထဲမှာပဲ ထားရမယ် — `<View>Hello</View>` ❌

### (b) Styling — `StyleSheet`, CSS မရှိဘူး

```jsx
const styles = StyleSheet.create({
  card: { padding: 16, backgroundColor: '#fff', borderRadius: 8 },
});
```
camelCase property, unit `px` မရေးရ၊ `className` မရှိဘူး။

### (c) Layout — Flexbox က default

```
Web default:    flexDirection: row
RN default:     flexDirection: column   👈 web နဲ့ ဆန့်ကျင်ဘက်
```

### (d) List — `FlatList`

```jsx
<FlatList
  data={expenses}
  keyExtractor={(item) => item.id}
  renderItem={({ item }) => <ExpenseCard {...item} />}
/>
```
Data များနိုင်တဲ့ list တိုင်းအတွက် `.map()` အစား ဒါကိုသုံး — visible item ချည်းပဲ render လို့ performance ကောင်းတယ်။

### (e) Touch — `onPress`

```jsx
<Pressable onPress={handleAdd}><Text>+ Add</Text></Pressable>
```
`onClick` → `onPress`, `onChange` → `onChangeText`

### (f) Navigation — Expo Router (file-based)

```
app/
├── _layout.jsx
├── index.jsx          → "/"
└── add-expense.jsx    → "/add-expense"
```

```jsx
import { useRouter } from 'expo-router';
const router = useRouter();
router.push('/add-expense');
```

### (g) Local Storage — `AsyncStorage` (async, `localStorage` မဟုတ်ဘူး)

```jsx
await AsyncStorage.setItem('expenses', JSON.stringify(expenses));
const data = await AsyncStorage.getItem('expenses');
```

### (h) Safe Area — notch/status bar ရှောင်ဖို့

```jsx
<SafeAreaView style={{ flex: 1 }}>{/* content */}</SafeAreaView>
```
