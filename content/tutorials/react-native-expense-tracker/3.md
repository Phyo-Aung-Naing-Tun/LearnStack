# Part 3: Android ဖုန်းပေါ် Install လုပ်နိုင်အောင် Build ချခြင်း

Expo Go app နဲ့ QR code scan လုပ်ကြည့်တာက **development preview** အတွက်ပဲ ဖြစ်ပါတယ် — friend/family ကို share ချင်ရင် (သို့) Expo Go မပါဘဲ standalone app အဖြစ် ဖုန်းထဲထည့်ချင်ရင် **APK file** တစ်ခု build ချရပါမယ်။ နည်းလမ်း ၂ မျိုးရှိပါတယ်။

## Option A — EAS Build (Cloud ပေါ်မှာ Build, အလွယ်ဆုံး)

Mac/Linux/Windows ဘာပဲသုံးသုံး အလုပ်လုပ်ပါတယ် — Android Studio install လုပ်စရာမလိုဘူး၊ Expo ရဲ့ cloud server ပေါ်မှာ build ပေးတာပါ။

### Step 1: EAS CLI Install + Login

```bash
npm install -g eas-cli
eas login
```

(Expo account မရှိသေးရင် https://expo.dev မှာ free account ဖွင့်ပါ)

### Step 2: Project ကို EAS နဲ့ ချိတ်

```bash
cd expense-tracker
eas build:configure
```

ဒါက `eas.json` file အသစ်တစ်ခု project root မှာ ဖန်တီးပေးပါလိမ့်မယ်။

### Step 3: `eas.json` ထဲမှာ APK Profile ထည့်ခြင်း

Default profile က `.aab` (Play Store အတွက်) ထုတ်ပေးတတ်ပါတယ်။ ဖုန်းထဲ တိုက်ရိုက် install လို့ရအောင် **APK** အနေနဲ့ ထုတ်ချင်ရင် `preview` profile ကို ဒီအတိုင်း ပြင်ပါ:

```json
{
  "build": {
    "preview": {
      "android": {
        "buildType": "apk"
      }
    },
    "production": {
      "android": {
        "buildType": "app-bundle"
      }
    }
  }
}
```

### Step 4: Build ခေါ်ခြင်း

```bash
eas build -p android --profile preview
```

- Build က cloud ပေါ်မှာ run ပါလိမ့်မယ် (၅-၁၅ မိနစ်ခန့် ကြာနိုင်ပါတယ်)
- ပြီးရင် terminal မှာ **download link** တစ်ခု (or QR code) ပြပါလိမ့်မယ်
- https://expo.dev/accounts/[your-account]/projects/expense-tracker/builds မှာလည်း build history ကြည့်လို့ရပါတယ်

### Step 5: APK ကို Android ဖုန်းထဲ Install ခြင်း

1. Terminal က link ကို ဖုန်းရဲ့ browser ထဲမှာ ဖွင့်ပြီး `.apk` file ကို download လုပ်ပါ (or QR code scan)
2. Download ပြီးရင် file ကို tap ပြီး install ကြိုးစားရင် **"Install blocked"** warning တက်နိုင်ပါတယ် — ဒါဆို:
   - **Settings → Security (or Apps) → Install unknown apps** ကိုသွား
   - Browser/File Manager app ကို "Allow from this source" ဖွင့်ပေးပါ
3. ပြန် install လုပ်ရင် app icon ဖုန်းထဲ ပေါ်လာပါလိမ့်မယ် — Expo Go မလိုဘဲ တိုက်ရိုက် ဖွင့်လို့ရပါပြီ

> **Native module (DateTimePicker) ပါလို့ Development Build လိုအပ်နိုင်တယ်** — `eas build --profile preview` က native code ကို ကိုယ်တိုင် compile ပေးမှာမို့ ဒီ concern ကို automatic ဖြေရှင်းပေးပါတယ်။ Expo Go ထဲမှာပဲ တိုက်ရိုက် run ကြည့်ရင်တော့ DateTimePicker ကဲ့သို့ native module အချို့က support မရှိနိုင်ပါ — ဒါကြောင့် feature အားလုံး test ကြည့်ချင်ရင် **build ချထားတဲ့ APK ကို install လုပ်ပြီးမှ** စမ်းသင့်ပါတယ်။

## Option B — Local Build (`expo run:android`, Offline/Free)

Cloud queue မစောင့်ချင်ဘူး၊ machine ကိုယ်တိုင် build ချင်ရင် ဒီနည်းသုံးနိုင်ပါတယ် — ဒါပေမယ့် **Android Studio + Android SDK** install ထားဖို့ လိုအပ်ပါတယ်။

### Step 1: Android Studio Install (Android SDK အတွက်)

https://developer.android.com/studio ကနေ download ပြီး install လုပ်ပါ။ Install ပြီးရင် Android SDK, Platform Tools (`adb`) တွေ auto-install ဖြစ်ပါလိမ့်မယ်။

### Step 2: `ANDROID_HOME` Environment Variable သတ်မှတ်ခြင်း (Mac/Linux ဥပမာ)

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
```

(`.zshrc` / `.bashrc` ထဲထည့်ထားရင် terminal ဖွင့်တိုင်း auto-load ဖြစ်ပါလိမ့်မယ်)

### Step 3: ဖုန်းကို Developer Mode ဖွင့်ပြီး Computer နဲ့ ချိတ်

1. Phone **Settings → About Phone → Build Number** ကို ၇ ကြိမ် tap → "Developer options" ဖွင့်ပေးမယ်
2. **Settings → Developer options → USB debugging** ကို ON လုပ်ပါ
3. Phone ကို USB cable နဲ့ computer ချိတ်ပြီး terminal မှာ စစ်ကြည့်ပါ:

```bash
adb devices
```

ဖုန်း serial number ပေါ်လာရင် ချိတ်ဆက်မှု အောင်မြင်ပါပြီ။

### Step 4: Build + Install တစ်ခါတည်း

```bash
npx expo run:android
```

ဒါက app ကို build ချပြီး ချိတ်ဆက်ထားတဲ့ ဖုန်းထဲ **တိုက်ရိုက် install** လုပ်ပေးပါလိမ့်မယ် (USB cable ချိတ်ပြီးရင် ဒီ command တစ်ကြောင်းတည်းနဲ့ ပြီးပါတယ်)။

## Option A vs Option B — ဘယ်တာသုံးသင့်လဲ

| | EAS Build (Cloud) | Local Build |
|---|---|---|
| Setup | လွယ်ကူ (login + configure ပဲ) | Android Studio install ရ (disk space များစားတယ်) |
| Build speed | Cloud queue စောင့်ရ (~10-15 min) | Machine spec ပေါ်မူတည် |
| Share ချင်ရင် | Link/QR code ကို ဘယ်သူ့ကိုမဆို ပို့လို့ရ | Physical USB connection လိုတယ် |
| Free tier limit | လစဉ် build count ကန့်သတ်ချက်ရှိ | Unlimited (ကိုယ့် machine) |
| **အကြံပြု** | Friend/family ကို app share ချင်ရင် | Daily development/testing အတွက် |

> **Tip:** Daily development (feature ထပ်ဖြည့်၊ bug fix) အတွက် `npx expo start` + Expo Go ကိုပဲ သုံးပါ (မြန်ဆုံး)။ Feature ပြီးမှ share/install-test လုပ်ချင်မှ ဒီ part ရဲ့ build steps တွေကို လုပ်ပါ။
