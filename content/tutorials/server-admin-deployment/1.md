# Day 1: VPS ဖန်တီးခြင်း & ပထမဆုံး SSH Connection

ဒီနေ့မှာ VPS server တစ်ခုကို ဖန်တီးပြီး SSH နဲ့ ပထမဆုံးအကြိမ် ဝင်ကြည့်တဲ့အထိ လေ့လာသွားပါမယ်။

---

## Step 1: VPS Provider ရွေးပါ

အောက်က provider တွေထဲက တစ်ခုခုမှာ account ဖွင့်ပါ:

- **DigitalOcean**
- **Linode**
- **Vultr**
- **AWS Lightsail**

$5-6/month plan ကနေ စလို့ရပါတယ်။ အချို့ provider တွေမှာ free trial credit ပါလေ့ရှိပါတယ်။

**OS ရွေးချယ်ခြင်း:** **Ubuntu 22.04 LTS** (သို့) **24.04 LTS** ကို ရွေးပါ။ LTS = Long Term Support ဖြစ်လို့ ပိုတည်ငြိမ်ပြီး documentation များပါတယ်။

**Server Size:** အသေးဆုံး plan (1GB RAM) နဲ့ practice လုပ်ဖို့ လုံလောက်ပါတယ်။

---

## Step 2: SSH Key ဖန်တီးခြင်း

သင့် **local machine** (ကိုယ့် PC/Laptop) ပေါ်မှာ terminal ဖွင့်ပြီး:
> 💡 **Windows Users များအတွက် မှတ်ချက်:** Windows 10/11 သုံးသူများအနေဖြင့် `ssh-keygen` command ကို **PowerShell** (သို့) **Command Prompt** တွင် တိုက်ရိုက်ရိုက်ထည့်နိုင်ပါသည်။ သို့မဟုတ် **Git Bash** ကိုလည်း အသုံးပြုနိုင်ပါသည်။

```bash
ssh-keygen -t ed25519 -C "your_email@example.com"
```

| Key | ရှင်းလင်းချက် |
|-----|------------|
| `-t ed25519` | ပိုမိုလုံခြုံတဲ့ algorithm ကိုသုံး |
| `-C` | Comment (သင့် email ထည့်ပါ) |

Enter နှိပ်ရင် default location (`~/.ssh/id_ed25519`) မှာ save ဖြစ်ပါမယ်။ Passphrase ထည့်ချင်ရင် ထည့်နိုင်ပါတယ်။

ဒါဆိုရင် ဖိုင် ၂ ခု ရလာပါမယ်:

- `id_ed25519` — **Private Key** (ဘယ်သူ့ကိုမှ မပြရ၊ လုံခြုံအောင်ထားပါ)
- `id_ed25519.pub` — **Public Key** (server မှာ ထည့်ဖို့)

Public key ကို ကြည့်ချင်ရင်:

```bash
cat ~/.ssh/id_ed25519.pub
```

---

## Step 3: VPS ဖန်တီးတဲ့အခါ SSH Key ထည့်ပါ

VPS provider dashboard မှာ server အသစ်ဖန်တီးတဲ့အချိန် "SSH Key" option ရှိပါလိမ့်မယ်။ အထက်က `cat` command နဲ့ ရလာတဲ့ public key (`ssh-ed25519 AAAA...` နဲ့စတာ) ကို copy ကူးပြီး paste လုပ်ပါ။

ဒီနည်းနဲ့ server ကနေ password မလိုဘဲ key ကနေတိုက်ရိုက် login ဝင်နိုင်မှာပါ။

---

## Step 4: Server ကို SSH နဲ့ ချိတ်ဆက်ပါ

Server ဖန်တီးပြီးရင် IPv4 Address ရလာပါမယ် (ဥပမာ `123.45.67.89`)။

```bash
ssh root@123.45.67.89
```

ပထမဆုံးအကြိမ် ဆက်တဲ့အခါ "Are you sure you want to continue connecting?" လို့ မေးပါလိမ့်မယ် — `yes` လို့ရိုက်ပါ။

> **🎯 Checkpoint:** `root@yourserver:~#` လို prompt ပေါ်လာရင် အောင်မြင်ပါပြီ။

---

## Key Takeaways

- VPS = Virtual Private Server — cloud provider ဆီက virtual machine တစ်ခု
- SSH = Secure Shell — server ကို secure connection နဲ့ remote control လုပ်တဲ့ protocol
- Private key က သင့်ရဲ့ သော့ (လူတိုင်းကို မပြရ)၊ Public key က သော့ခလောက် (server မှာ ထားခဲ့)
