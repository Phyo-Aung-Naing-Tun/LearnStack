# Day 13: Firewall Concept & ufw Install

### Firewall ဆိုတာဘာလဲ

Firewall က server ကို ဝင်/ထွက် traffic တွေကို rule အတိုင်း filter လုပ်ပေးတဲ့ security layer ပါ။ လိုအပ်တဲ့ port တွေကိုပဲ ဖွင့်ပြီး၊ ကျန်တာအားလုံး default အနေနဲ့ ပိတ်ထားခြင်းက security best practice ပါ။

### ufw (Uncomplicated Firewall)

Ubuntu ပေါ်မှာ firewall config လုပ်ဖို့ အလွယ်ဆုံး tool ပါ (iptables ကို wrap ထားတဲ့ simplified interface)။

### Install & Status

```bash
sudo apt install ufw -y
sudo ufw status
```

Default အနေနဲ့ `inactive` ဖြစ်နေမှာပါ။

### Default Policy သတ်မှတ်ခြင်း

```bash
sudo ufw default deny incoming
sudo ufw default allow outgoing
```

- **Incoming** — server ဆီ ဝင်လာတဲ့ traffic — default **deny** (ပိတ်ထား)
- **Outgoing** — server ကနေ ထွက်သွားတဲ့ traffic — default **allow** (ဖွင့်ထား)

**⚠️ အရေးကြီးသတိပေးချက်:** `ufw enable` မလုပ်ခင် SSH port ကို allow လုပ်ဖို့ **မမေ့ပါနဲ့** — မဟုတ်ရင် server ထဲ ဝင်လို့ လုံးဝ မရတော့ပါဘူး (lockout)။
