# Day 10: fail2ban ဖြင့် Brute Force Attack ကာကွယ်ခြင်း

`fail2ban` က login attempt ကို monitor လုပ်ပြီး၊ အကြိမ်ကြိမ် fail ဖြစ်တဲ့ IP address ကို temporary ban လုပ်ပေးတဲ့ tool ပါ။

### Install လုပ်ခြင်း

```bash
sudo apt update
sudo apt install fail2ban -y
```

### Config File Setup

Default config file ကို တိုက်ရိုက် မပြင်ပါနဲ့ — `jail.local` ဆိုတဲ့ copy တစ်ခု ဖန်တီးပါ:

```bash
sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local
sudo nano /etc/fail2ban/jail.local
```

`[sshd]` section ကို ရှာပြီး အောက်ပါအတိုင်း ပြင်ပါ:

```ini
[sshd]
enabled = true
port = 2222
maxretry = 5
bantime = 3600
findtime = 600
```

- `maxretry = 5` — ၅ ကြိမ် fail ရင် ban
- `bantime = 3600` — ၁ နာရီ ban (စက္ကန့်ပေါင်း)
- `findtime = 600` — ၁၀ မိနစ်အတွင်း ၅ ကြိမ် fail ဖြစ်ရင် count

### fail2ban Service ကို Enable/Restart လုပ်ခြင်း

```bash
sudo systemctl enable fail2ban
sudo systemctl restart fail2ban
```

### Status စစ်ခြင်း

```bash
sudo fail2ban-client status
sudo fail2ban-client status sshd
```

Banned IP list, current failed attempts စတာတွေ ပြပေးပါလိမ့်မယ်။

## Week 2 Final Checklist

- [ ] Non-root user ဖန်တီးပြီး `sudo` privilege ပေးထားပြီ
- [ ] Non-root user အတွက် SSH key login setup လုပ်ပြီး test ပြီးပါပြီ
- [ ] `PermitRootLogin no` နဲ့ `PasswordAuthentication no` config ချထားပြီ
- [ ] SSH port ကို default 22 ကနေ ပြောင်းထားပြီ (optional)
- [ ] `fail2ban` install လုပ်ပြီး sshd jail active ဖြစ်နေပြီ

Week 3 မှာ — networking အခြေခံ (DNS, domain point လုပ်နည်း, ports, `ufw` firewall rules) တွေကို အသေးစိတ် သင်ရမှာပါ။
