# Day 5: Process Management & Monitoring

Server ပေါ်မှာ ဘာတွေ run နေလဲ၊ resource ဘယ်လောက်သုံးနေလဲ သိဖို့ အရမ်းအရေးကြီးပါတယ်။

---

## Running Processes ကြည့်ခြင်း

```bash
ps aux
```

Column တွေရဲ့ အဓိပ္ပါယ်:

| Column | Meaning |
|--------|---------|
| USER | Process owner |
| PID | Process ID (unique number) |
| %CPU | CPU usage |
| %MEM | Memory usage |
| COMMAND | ဘာ command run နေလဲ |

---

## Real-Time Monitoring

### htop (recommended)

```bash
sudo apt install htop -y
htop
```

`htop` က colorful interface နဲ့ CPU/RAM bar တွေ၊ process list တွေကို real-time ပြပေးပါတယ်။

Navigation:
- `↑↓` — ရွှေ့ဖို့
- `F9` — process kill
- `F10` (သို့) `q` — ထွက်ဖို့

### top (built-in)

```bash
top
# q နှိပ်ရင် ထွက်မယ်
```

---

## Process ရပ်ခြင်း

```bash
kill 1234          # PID 1234 ကို ရပ် (graceful)
kill -9 1234       # force kill (တခြားနည်းနဲ့မရမှသုံး)
killall nginx      # nginx process အားလုံးရပ်
```

> `-9` (SIGKILL) က process ကို ချက်ချင်းရပ်ခိုင်းတာပါ — graceful shutdown မဟုတ်လို့ data loss ဖြစ်နိုင်ပါတယ်။ တတ်နိုင်ရင် `kill` ကို `-9` မပါဘဲ အရင်သုံးပါ။

---

## Disk Space & Memory

```bash
df -h               # disk space (human-readable)
df -h /var          # specific folder အတွက်

free -h             # RAM usage
free -h -s 2        # ၂ စက္ကန့်တစ်ခါ auto-refresh

du -sh *            # folder တစ်ခုချင်းစီရဲ့ size
du -sh /var/log     # log folder size ကြည့်
```

---

## System Info

```bash
uname -a            # kernel version
lsb_release -a      # Ubuntu version
uptime              # server ဘယ်လောက်ကြာကြာ on ထားလဲ
who                 # ဘယ်သူတွေ login ဝင်ထားလဲ
w                   # who + what they're doing
```

## Week 1 Final Checklist

ဒီစာရင်းအားလုံးကို လုပ်နိုင်ရင် Week 1 ပြီးပါပြီ:

- [ ] VPS ဖန်တီးပြီး SSH key setup လုပ်နိုင်ပြီ

- [ ] `apt update && apt upgrade` run နိုင်ပြီး software အသစ် install လုပ်နိုင်ပြီ
- [ ] `ps`, `top`/`htop`, `df -h`, `free -h` နဲ့ server status ကြည့်နိုင်ပြီ
