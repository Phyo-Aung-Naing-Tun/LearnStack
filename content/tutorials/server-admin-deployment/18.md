# Day 18: Laravel (PHP-FPM) ကို Nginx နဲ့ ချိတ်ခြင်း

ဒီနေ့မှာ PHP-FPM ကို install လုပ်ပြီး Laravel app ကို Nginx နဲ့ ချိတ်ဆက်နည်း လေ့လာပါမယ်။

---

## PHP-FPM ဆိုတာဘာလဲ

Nginx ကိုယ်တိုင် PHP process ကို execute လုပ်နိုင်မှာ မဟုတ်ပါဘူး။ **PHP-FPM (FastCGI Process Manager)** ဆိုတာ PHP code ကို execute လုပ်ပေးတဲ့ separate service တစ်ခုပါ။ Nginx က PHP file request လာတဲ့အခါ PHP-FPM ဆီကို socket ကနေ pass လုပ်ပေးပြီး PHP-FPM က process လုပ်ပြီး response ပြန်ပေးပါတယ်။

```
Client → Nginx (port 80) → PHP-FPM (unix socket) → PHP process → Response
```

---

## PHP & PHP-FPM Install

```bash
sudo apt update
sudo apt install php-fpm php-mysql php-mbstring php-xml php-curl php-zip php-bcmath -y
```

### PHP Version Confirm လုပ်ပါ

```bash
php -v
```

### PHP-FPM Status စစ်ပါ

```bash
# Version ပေါ်မူတည်ပြီး နာမည်ကွဲနိုင်ပါတယ် (php8.1-fpm, php8.3-fpm)
sudo systemctl status php8.3-fpm
```

### PHP-FPM Socket Location ရှာပါ

```bash
sudo find /var/run/php/ -name "*.sock"
# Output: /var/run/php/php8.3-fpm.sock
```

> 💡 Config ထဲမှာ socket path ကို မှန်မမှန် စစ်ဖို့ ဒီ command ကို သုံးပါ။

---

## Laravel အတွက် Server Block

```bash
sudo nano /etc/nginx/sites-available/laravel-app.com
```

```nginx
server {
    listen 80;
    server_name laravel-app.com www.laravel-app.com;

    root /var/www/laravel-app.com/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;

    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
```

## Config ရဲ့ အရေးကြီးတဲ့ အပိုင်းတွေ

### 1. root directive

```nginx
root /var/www/laravel-app.com/public;
```

Laravel ရဲ့ `public/` folder ကို root အနေနဲ့ ညွှန်ရပါတယ် — project root (`/var/www/laravel-app.com`) မဟုတ်ပါ။ Project root ညွှန်ရင် `.env`, `vendor/` တွေ web ကနေ access ဝင်နိုင်သွားပြီး **လုံခြုံရေး ချိုးဖောက်မှု** ဖြစ်သွားနိုင်ပါတယ်။

### 2. try_files (Laravel Routing)

```nginx
try_files $uri $uri/ /index.php?$query_string;
```

- File/folder ကိုဦးစွာ ရှာ
- မတွေ့ရင် `index.php` ဆီ route လုပ် (Laravel ရဲ့ front controller)
- ဒါ မပါရင် Laravel routing အလုပ်မလုပ်ပါဘူး

### 3. PHP-FPM ချိတ်ဆက်မှု

```nginx
location ~ \.php$ {
    fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
    fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
    include fastcgi_params;
}
```

`.php` extension ပါတဲ့ request တိုင်း PHP-FPM socket ဆီ pass လုပ်ပါတယ်။

### 4. Hidden File Protection

```nginx
location ~ /\.(?!well-known).* {
    deny all;
}
```

`.env`, `.git` ကဲ့သို့သော hidden file တွေကို web ကနေ access မဝင်နိုင်အောင် ပိတ်ထားပါတယ်။ `well-known` ကို exclude ထားတာ Let's Encrypt SSL verification အတွက်ပါ (Week 7 မှာ သုံးပါမယ်)။

## Enable & Test

```bash
sudo ln -s /etc/nginx/sites-available/laravel-app.com /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

### Laravel Permission Setup

```bash
sudo chown -R www-data:www-data /var/www/laravel-app.com
sudo chmod -R 755 /var/www/laravel-app.com/storage
sudo chmod -R 755 /var/www/laravel-app.com/bootstrap/cache
```

## Key Takeaways

- Nginx ကိုယ်တိုင် PHP execute မလုပ်နိုင် — PHP-FPM socket ကနေ pass လုပ်ပေးတာ
- Laravel root ကို `public/` folder ညွှန်ရပါတယ် — project root မဟုတ်
- `try_files ... /index.php?$query_string` က Laravel routing အတွက် မဖြစ်မနေ လိုပါတယ်
- Hidden file protection directive က `.env` leak ကာကွယ်ဖို့ အရေးကြီးပါတယ်
