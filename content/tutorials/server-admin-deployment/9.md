# Day 9: SSH Port ပြောင်းခြင်း (Optional ဒါပေမဲ့ အကြံပြု)

Default SSH port (22) ကို attacker bot တွေက အမြဲ scan လုပ်ပါတယ်။ Port ပြောင်းလိုက်ရင် automated attack အများစုကို ရှောင်နိုင်ပါတယ်။

### Port ပြောင်းနည်း

```bash
sudo nano /etc/ssh/sshd_config
```

```
Port 2222
```

(2222 အစား 1024-65535 ကြားက ဂဏန်းတစ်ခုခု ရွေးနိုင်ပါတယ်)

### Firewall ထဲမှာ Port အသစ်ကို ဖွင့်ခြင်း

> ⚠️ **သတိပေးချက်:** SSH ကို Restart မချခင် Firewall (ဥပမာ - `ufw`) ထဲမှာ Port အသစ် (ဒီဥပမာမှာ `2222`) ဖွင့်ထားတာ သေချာပါစေ။ မဟုတ်ပါက သင်ကိုယ်တိုင်ပါ Server ထဲ ဝင်မရတော့ဘဲ Lockout ဖြစ်သွားနိုင်ပါတယ်။

```bash
sudo ufw allow 2222/tcp
sudo systemctl restart ssh
```

### Login ဝင်တဲ့အခါ Port တိုက်ရိုက် ဖော်ပြရန်

```bash
ssh -p 2222 yourname@your-server-ip
```

**Checkpoint:** Port အသစ်နဲ့ login ဝင်လို့ရရင် အောင်မြင်ပါပြီ။ Port 22 ဟောင်းကို firewall ကနေ ပိတ်ပစ်နိုင်ပါတယ် (Week 3 firewall topic မှာ အသေးစိတ်ပြန်ပြောပါမယ်)။
