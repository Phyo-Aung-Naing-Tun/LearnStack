# Day 7: SSH Key ကို User အသစ်အတွက် Setup လုပ်ခြင်း

Week 1 မှာ root အတွက် SSH key setup လုပ်ခဲ့ပါတယ်။ User အသစ်အတွက်လည်း ထပ်လုပ်ရပါမယ်။

### Local machine ကနေ Public Key ကို Copy ပို့ခြင်း (Method 1: ssh-copy-id)

```bash
ssh-copy-id yourname@your-server-ip
```

Password တစ်ကြိမ် တောင်းမှာပါ — root အတွက် ဖန်တီးထားတဲ့ key ကိုပဲ အသုံးပြုချင်ရင် ဒါလောက်ပါပဲ။

### Method 2: Manual Setup

Server ပေါ်မှာ (user အသစ်ဖြင့်):

```bash
mkdir -p ~/.ssh
chmod 700 ~/.ssh
nano ~/.ssh/authorized_keys
```

Local machine က `cat ~/.ssh/id_ed25519.pub` output ကို paste ထည့်ပါ။

```bash
chmod 600 ~/.ssh/authorized_keys
```

### Test လုပ်ခြင်း

Local machine ကနေ:

```bash
ssh yourname@your-server-ip
```

Password မလိုဘဲ ဝင်နိုင်ရင် setup ပြီးပါပြီ။
