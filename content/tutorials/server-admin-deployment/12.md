# Day 12: Ports အခြေခံ

### Port ဆိုတာဘာလဲ

Server တစ်ခုမှာ service အများကြီး တစ်ပြိုင်နက်တည်း run နေနိုင်ပါတယ် (web server, database, SSH...) — Port က ဒီ service တွေကို ခွဲခြားပေးတဲ့ "အခန်းနံပါတ်" လိုမျိုးပါ။ IP address တစ်ခုတည်းပေါ်မှာ port ကွဲပြားစွာ listen လုပ်နေတဲ့ service အများကြီး ရှိနိုင်ပါတယ်။

### Common Ports

| Port | Service |
|---|---|
| **22** | SSH |
| **80** | HTTP (web, unencrypted) |
| **443** | HTTPS (web, encrypted) |
| **3306** | MySQL |
| **5432** | PostgreSQL |
| **6379** | Redis |
| **3000** | Node.js dev server (default) |
| **8080** | Alternative HTTP (dev/proxy) |

### Server ပေါ်မှာ ဘယ် port တွေ Listen လုပ်နေလဲ ကြည့်ခြင်း

```bash
sudo ss -tulpn
```

- `-t` — TCP
- `-u` — UDP
- `-l` — Listening ဖြစ်နေတဲ့ port တွေပဲ ပြ
- `-p` — Process name ပါပြ
- `-n` — Numeric (service name အစား port number ပြ)

Output ဥပမာ:

```
State   Local Address:Port   Process
LISTEN  0.0.0.0:22           sshd
LISTEN  0.0.0.0:80           nginx
LISTEN  127.0.0.1:3306       mysqld
```

**Note:** `127.0.0.1:3306` ဆိုတာ localhost ကနေပဲ access လို့ရတယ် (public မှာ မဖွင့်ထား) — database အတွက် ဒါက security best practice ပါ။
