# Web Developer အတွက် Server Administration & Secure Deployment Course

JS, PHP, Laravel, Vue, Nuxt တတ်ပြီးသား developer တစ်ယောက်အနေနဲ့ သင့်ရဲ့ project တွေကို ကိုယ်ပိုင် server (VPS) ပေါ်မှာ **လုံခြုံစွာ** deploy လုပ်နိုင်ဖို့ လိုအပ်တဲ့ knowledge ကို အခြေခံကနေ တည်ဆောက်ပေးမယ့် course ဖြစ်ပါတယ်။

**ကြာချိန်** — ၈ ပတ် (Week 1-8)၊ တစ်ပတ်ကို ၃-၅ နာရီ practice လုပ်ရင် အဆင်ပြေမယ်

**လိုအပ်တာ** — VPS တစ်ခု (DigitalOcean, Linode, Vultr, AWS Lightsail — $5-6/month နဲ့ စလို့ရတယ်)

## Course Outline

- **Week 1** — Linux အခြေခံ (Terminal, SSH, Commands, Permissions, Package Management)
- **Week 2** — SSH & User Management (Security အစ)
- **Week 3** — Networking အခြေခံ (DNS, Ports, Firewall)
- **Week 4** — Web Server (Nginx)
- **Week 5** — PHP/Laravel Deployment
- **Week 6** — Node.js Deployment (Vue/Nuxt)
- **Week 7** — HTTPS/SSL & Security Hardening
- **Week 8** — Deployment Workflow & Monitoring

အခု **Week 1** ကို စလိုက်ရအောင်။
