# Day 8: Root Login ပိတ်ခြင်း & Password Authentication ပိတ်ခြင်း

**⚠️ သတိပြုရန်:** ဒီ step ကို မလုပ်ခင် non-root user နဲ့ SSH key login စမ်းသပ်ပြီးသားဖြစ်ဖို့ လိုအပ်ပါတယ် — မဟုတ်ရင် server ထဲ ဝင်လို့ မရတော့ပါဘူး။

### SSH Config File ဖွင့်ခြင်း

```bash
sudo nano /etc/ssh/sshd_config
```

### အောက်ပါ line တွေကို ရှာပြီး ပြင်ပါ

```
PermitRootLogin no
PasswordAuthentication no
PubkeyAuthentication yes
```

- `PermitRootLogin no` — root ကို SSH ကနေ တိုက်ရိုက် login ဝင်ခွင့် ပိတ်
- `PasswordAuthentication no` — password နဲ့ login ဝင်ခွင့် ပိတ် (SSH key ပဲ ခွင့်ပြု)
- `PubkeyAuthentication yes` — SSH key login ကို ခွင့်ပြု

### SSH Service ကို Restart လုပ်ခြင်း

```bash
sudo systemctl restart sshd
```

### Test လုပ်ခြင်း (အရေးကြီး)

**Terminal window အသစ်တစ်ခု ဖွင့်ထားပြီး** login ပြန်စမ်းကြည့်ပါ (current session ကို မပိတ်ပါနဲ့):

```bash
ssh yourname@your-server-ip
```

ဝင်လို့ရရင် Terminal window ဟောင်းကို ပိတ်လို့ရပါပြီ။ ဝင်မရဘူးဆိုရင် window ဟောင်းက Session ထဲမှာပဲ config ကို ပြန်ပြင်ပါ။
