# Day 2: Basic Navigation Commands

Server ထဲ ဝင်ပြီးရင် အောက်က command တွေကို တစ်ခုချင်းစီ လက်တွေ့ run ကြည့်ပါ။

---

## လက်ရှိနေရာ ကြည့်ခြင်း

```bash
pwd
```

**P**rint **W**orking **D**irectory — လက်ရှိ folder path ကိုပြပါတယ်။ ဥပမာ `/root`

---

## Folder ထဲက ဖိုင်တွေ ကြည့်ခြင်း

```bash
ls
ls -la
```

| Flag | Meaning |
|------|---------|
| `-l` | Detail (permission, size, date) ပြပေး |
| `-a` | Hidden files (`.` နဲ့စတဲ့ဖိုင်တွေ) ပါပြပေး |

---

## Folder ပြောင်းခြင်း

```bash
cd /var/www       # /var/www folder ထဲ ဝင်
cd ..             # တစ်ဆင့်ပြန်တက်
cd ~              # home directory ပြန်သွား
cd /              # root directory (system အထိပ်)
```

---

## Folder & File ဖန်တီးခြင်း

```bash
mkdir test-folder          # folder အသစ်
cd test-folder
touch hello.txt            # empty file အသစ်
nano hello.txt             # nano text editor နဲ့ဖွင့်
```

`nano` က beginner-friendly text editor ပါ။ စာရိုက်ပြီးရင်:

- `Ctrl + O` → Save
- `Enter` → Confirm filename
- `Ctrl + X` → Exit

---

## ဖိုင်ထဲက Content ကြည့်ခြင်း

```bash
cat hello.txt
```

---

## Copy, Move, Delete

```bash
cp hello.txt hello-copy.txt    # copy
mv hello-copy.txt renamed.txt  # rename/move
rm renamed.txt                 # ဖိုင်ဖျက်
rm -r test-folder              # folder တစ်ခုလုံးဖျက်
```

> ⚠️ `rm -r` က undo မရပါ — သေချာမှသုံးပါ။

`/home` အောက်မှာ folder အသစ် ၃ ခု ဖန်တီးပြီး၊ တစ်ခုစီထဲမှာ text file တစ်ခုစီထည့်ကြည့်ပါ။ ပြီးရင် `ls -la` နဲ့ စစ်ကြည့်ပါ။

```bash
cd /home

cd folder1 && touch file1.txt

ls -la */
```

---

## Key Takeaways

- `pwd`, `ls`, `cd` က navigation အတွက် အခြေခံ command ၃ ခု
- `mkdir`, `touch`, `nano` က file/folder ဖန်တီးဖို့
- `cp`, `mv`, `rm` က manage လုပ်ဖို့
- Tab key နှိပ်ရင် auto-complete လုပ်ပေးပါတယ် (အရမ်းအသုံးဝင်)
