# Day 3: File Permissions & Ownership

Linux မှာ file/folder တိုင်းမှာ **owner**, **group**, **others** သုံးမျိုးအတွက် permission ခွဲထားပါတယ်။ ဒါက security အတွက် အခြေခံအကျဆုံး concept ပါ။

---

## Permission ကြည့်ခြင်း

```bash
ls -l
```

ရလာတဲ့ output ဥပမာ:

```
-rw-r--r-- 1 root root 0 Aug 7 10:00 hello.txt
drwxr-xr-x 2 root root 4096 Aug 7 10:00 myfolder
```

ပထမဆုံး character:

| Character | Meaning |
|-----------|---------|
| `-` | Regular file |
| `d` | Directory |
| `l` | Symbolic link |

နောက် ၉ လုံးကို ၃ အုပ်စု ခွဲပါတယ် (owner—group—others):

```
rwx | r-x | r--
 ↑     ↑     ↑
owner  group others
```

| Letter | Permission |
|--------|-----------|
| `r` | Read (ဖတ်ခွင့်) |
| `w` | Write (ရေးခွင့်) |
| `x` | Execute (run ခွင့်) |

---

## chmod — Permission ပြောင်းခြင်း

### Symbolic Mode

```bash
chmod u+x script.sh      # user(owner) ကို execute ခွင့်ပေး
chmod g-w file.txt        # group ဆီက write ခွင့်ပြန်ယူ
chmod o+r file.txt        # others ကို read ခွင့်ပေး
chmod a+r file.txt        # all (အားလုံး) ကို read ခွင့်ပေး
```

### Numeric Mode (ပိုအသုံးများ)

```
read    = 4
write   = 2
execute = 1
```

| Command | Owner | Group | Others | Meaning |
|---------|-------|-------|--------|---------|
| `chmod 644` | rw- (6) | r-- (4) | r-- (4) | File standard |
| `chmod 755` | rwx (7) | r-x (5) | r-x (5) | Folder/script standard |
| `chmod 777` | rwx (7) | rwx (7) | rwx (7) | ⚠️ အားလုံးခွင့်ပြု (မသုံးသင့်) |

Web development မှာ:

```bash
# Web files
chmod 644 *.php
chmod 644 *.css *.js

# Folders
chmod 755 storage
chmod 755 bootstrap/cache
```

---

## chown — Owner ပြောင်းခြင်း

```bash
# Owner + Group တစ်ခါတည်းပြောင်း
chown www-data:www-data /var/www/myapp

# Owner တစ်ခုပဲပြောင်း
chown root file.txt

# Recursive (folder တစ်ခုလုံး)
chown -R www-data:www-data /var/www/myapp
```

Web server (Nginx/Apache) က `www-data` user နဲ့ run တာမို့ Laravel/Nuxt deploy လုပ်ရင် `storage/` folder တွေကို `www-data` user ဝင်ရေးလို့ရအောင် `chown` ပေးရပါတယ်။

## 🧪 Practice Exercise

file ၃ ခု ဖန်တီးပြီး permission အမျိုးမျိုးချထားကြည့်ပါ:

```bash
touch public.txt private.txt script.sh
chmod 644 public.txt
chmod 600 private.txt
chmod 755 script.sh
ls -l
```

---

## Key Takeaways

- `644` for files, `755` for folders/scripts — standard web permissions
- `www-data` က web server user — သူ့ကို file owner ပေးဖို့ လိုတတ်တယ်
- **Never use `777`** — security risk အကြီးကြီးပါ
