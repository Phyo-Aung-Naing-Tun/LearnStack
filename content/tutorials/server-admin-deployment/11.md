# Day 11: DNS & Domain Name အခြေခံ

### DNS ဆိုတာဘာလဲ

DNS (Domain Name System) က domain name (ဥပမာ `myapp.com`) ကို IP address (ဥပမာ `123.45.67.89`) ကို ပြောင်းပေးတဲ့ system ပါ။ လူတွေက IP address မှတ်ရခက်တဲ့အတွက် domain name သုံးပါတယ်။

### DNS Record အမျိုးအစားများ

| Record Type | ဘာလုပ်လဲ | ဥပမာ |
|---|---|---|
| **A Record** | Domain → IPv4 address | `myapp.com → 123.45.67.89` |
| **AAAA Record** | Domain → IPv6 address | `myapp.com → 2001:db8::1` |
| **CNAME** | Domain → တခြား domain (alias) | `www.myapp.com → myapp.com` |
| **MX** | Email server ညွှန်းတယ် | Mail routing |
| **TXT** | Text data (verification, SPF စသည်) | Domain ownership verify |

### Domain ကို VPS IP ကို Point လုပ်နည်း

Domain registrar (Namecheap, GoDaddy, Cloudflare စသည်) dashboard ထဲမှာ:

1. DNS management page ဝင်ပါ
2. **A Record** အသစ် ဖန်တီးပါ:
   - **Host/Name:** `@` (root domain အတွက်) သို့ `www`
   - **Value/Points to:** VPS ရဲ့ IPv4 address
   - **TTL:** Default (Auto) ထားလို့ရပါတယ်

```
Type: A
Host: @
Value: 123.45.67.89
TTL: Auto
```

`www` subdomain ကိုပါ point ချင်ရင် A record ထပ်တစ်ခု (သို့) CNAME ဖန်တီးပါ:

```
Type: A
Host: www
Value: 123.45.67.89
```

### DNS Propagation

DNS change တွေဟာ ချက်ချင်း update ဖြစ်ချင်ချင် မဖြစ်ပါဘူး — worldwide DNS server တွေအားလုံး sync ဖြစ်ဖို့ **၅ မိနစ်ကနေ ၄၈ နာရီအထိ** ကြာနိုင်ပါတယ် (ပုံမှန် ၁-၂ နာရီအတွင်း ပြီးလေ့ရှိပါတယ်)။

### DNS Point ဖြစ်မဖြစ် စစ်ခြင်း

```bash
# Local machine ကနေ
nslookup myapp.com
dig myapp.com

# ping နဲ့လည်း စစ်လို့ရ
ping myapp.com
```

Output ထဲက IP address သင့် VPS IP နဲ့ ကိုက်ညီရင် DNS point ပြီးပါပြီ။
