# Day 15: Full Networking Setup Checkpoint

### End-to-End Test

Week 3 ပြီးရင် အောက်ပါအတိုင်း confirm လုပ်ကြည့်ပါ:

```bash
# 1. DNS point ဖြစ်မဖြစ် စစ်
dig myapp.com

# 2. Listening ports ကြည့်
sudo ss -tulpn

# 3. Firewall status ကြည့်
sudo ufw status verbose

# 4. SSH port အသစ်နဲ့ login test (terminal အသစ်ဖွင့်ပြီး)
ssh -p 2222 yourname@myapp.com
```

### Practice Exercise

Nginx ကို install လုပ်ပြီး (Week 4 မှာ အသေးစိတ်ပြောပါမယ်, ဒီနေရာမှာ port test လုပ်ဖို့ပဲ):

```bash
sudo apt install nginx -y
sudo ufw allow 'Nginx Full'
```

ပြီးရင် browser ကနေ `http://your-domain.com` ကို ဝင်ကြည့်ပါ — Nginx default welcome page ပေါ်လာရင် DNS + Firewall + Web server ချိတ်ဆက်မှု အောင်မြင်ပါပြီ။

---

## Week 3 Final Checklist

- [ ] DNS A record ဖန်တီးပြီး domain ကို VPS IP ကို point လုပ်ထားပြီ
- [ ] `dig`/`nslookup` နဲ့ DNS propagation confirm လုပ်ပြီ
- [ ] Port ဆိုတာဘာလဲ၊ common port list (22, 80, 443, 3306) နားလည်ပြီ
- [ ] `ss -tulpn` နဲ့ listening ports ကြည့်နိုင်ပြီ
- [ ] `ufw` install လုပ်ပြီး default deny/allow policy သတ်မှတ်ထားပြီ
- [ ] SSH, HTTP, HTTPS port တွေ allow လုပ်ပြီး firewall enable ထားပြီ

---

### နောက်တစ်ပတ်

Week 4 မှာ — Nginx web server ကို install လုပ်ပြီး, virtual host/server block ဖန်တီးနည်း, static file serve လုပ်နည်း, PHP-FPM နဲ့ Node.js app တွေကို reverse proxy ချိတ်နည်း တွေကို လေ့လာပါမယ်။

**Tip:** Firewall rule အသစ် ချမှတ်တိုင်း terminal session အသစ်တစ်ခု ဖွင့်ပြီး confirm လုပ်ပါ — SSH port ကို မတော်တဆ ပိတ်မိရင် server ထဲ ဝင်လို့ မရတော့ပါဘူး (VPS provider ရဲ့ web console ကနေမှ ပြန်ပြင်ရနိုင်ပါတယ်)။
