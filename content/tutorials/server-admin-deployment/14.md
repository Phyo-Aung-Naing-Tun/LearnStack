# Day 14: Firewall Rules ချမှတ်ခြင်း

### လိုအပ်တဲ့ Port တွေ ဖွင့်ခြင်း

```bash
# SSH (Week 2 မှာ port ပြောင်းထားရင် အဲ့ port ကို သုံးပါ)
sudo ufw allow 2222/tcp

# HTTP
sudo ufw allow 80/tcp

# HTTPS
sudo ufw allow 443/tcp
```

Service name နဲ့လည်း allow လို့ရပါတယ်:

```bash
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'    # port 80 + 443 နှစ်ခုစလုံး
```

### Firewall ကို Enable လုပ်ခြင်း

```bash
sudo ufw enable
```

Confirmation prompt ပေါ်လာရင် `y` နှိပ်ပါ။

### Status စစ်ခြင်း

```bash
sudo ufw status verbose
```

Output ဥပမာ:

```
Status: active
Logging: on (low)
Default: deny (incoming), allow (outgoing)

To                         Action      From
--                         ------      ----
2222/tcp                   ALLOW       Anywhere
80/tcp                     ALLOW       Anywhere
443/tcp                    ALLOW       Anywhere
```

### Rule ဖျက်ခြင်း

```bash
sudo ufw status numbered      # rule တွေကို number နဲ့ ပြ
sudo ufw delete 3             # number 3 ဖျက်
```

သို့မဟုတ်:

```bash
sudo ufw delete allow 8080/tcp
```

### Specific IP ကနေပဲ Access ခွင့်ပြုခြင်း (Advanced)

Database port လို sensitive port တွေကို specific IP ကနေပဲ ခွင့်ပြုချင်ရင်:

```bash
sudo ufw allow from 203.0.113.10 to any port 3306
```
