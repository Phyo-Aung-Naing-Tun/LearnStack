# Day 4: Package Management (apt)

Ubuntu/Debian based system တွေမှာ software install လုပ်ဖို့ `apt` (Advanced Package Tool) ကို သုံးပါတယ်။ Server အသစ်ရတိုင်း ဒီ command တွေက အမြဲ ပထမဆုံး run ရမယ့် command တွေပါ။

---

## System Update

```bash
sudo apt update        # package list ကို update (install မလုပ်သေး)
sudo apt upgrade -y    # installed packages အားလုံး upgrade
```

`-y` flag က confirmation prompt တွေကို auto-yes လုပ်ပေးပါတယ်။

> **Server အသစ်ရတိုင်း ဒါ ၂ လုံးကို ပထမဆုံး run ပါ။**

---

## Software Install

```bash
sudo apt install nginx -y
sudo apt install git -y
sudo apt install curl -y
sudo apt install htop -y
```

Package တစ်ခုထက်ပိုပြီး တစ်ခါတည်း install လို့လည်းရပါတယ်:

```bash
sudo apt install nginx git curl htop -y
```

---

## Software Remove

```bash
sudo apt remove nginx              # package ဖျက် (config ကျန်)
sudo apt purge nginx               # package + config အကုန်ဖျက်
sudo apt autoremove                # မလိုတော့တဲ့ dependencies ဖျက်
```

---

## Package ရှာခြင်း

```bash
apt search nginx                   # nginx နဲ့ဆိုင်တာရှာ
apt show nginx                     # package info ကြည့်
dpkg -l | grep nginx               # install ဖြစ်မဖြစ် စစ်
```

---

## Useful Tools to Install

```bash
# System monitoring
sudo apt install htop -y           # process viewer (top ထက် ပိုကောင်း)

# Network tools
sudo apt install net-tools -y      # ifconfig, netstat
sudo apt install curl wget -y      # download/file transfer

# Compression
sudo apt install zip unzip -y

# Version control
sudo apt install git -y
```

---

## 🧪 Practice Exercise

```bash
# 1. Update your system first
sudo apt update && sudo apt upgrade -y

# 2. Install common tools
sudo apt install git curl htop net-tools -y

# 3. Verify installations
git --version
curl --version
htop --version
```

---

## Key Takeaways

- `apt update` + `apt upgrade` = server အသစ်တိုင်းရဲ့ first step
- `apt install` နဲ့ software install — `-y` flag သုံးပါ
- `apt purge` က config ပါ တစ်ခါတည်းဖျက်ပေးတယ်
